# Crazy Animal Farm

제멋대로인 코믹 동물을 포획하고 농장 일에 배치하는 2D 탑뷰 웹 게임입니다.

## 현재 구현 범위

현재는 **Phase 6 — 맵 이동과 저장**, **확장 1 — 장비와 제작**, **전체화면 메뉴 UI 개편**, **확장 2 — 음식과 허기**까지 작성되어 있습니다.

- Vite + React + TypeScript 프로젝트 구성
- 게임 시작 전 타이틀 화면과 저장 슬롯 선택
- 맨 위 자동저장 슬롯과 수동 저장 슬롯 5개
- 인게임 옵션에서 빈 슬롯 신규 저장과 기존 슬롯 덮어쓰기
- Phaser 3과 Zustand 의존성 구성
- React 안에 Phaser Canvas 마운트
- React StrictMode 재마운트 시 Phaser 인스턴스와 Canvas 정리
- 브라우저 크기를 꽉 채우는 Phaser RESIZE 스케일과 전체화면 Canvas
- Arcade Physics 기본 설정
- Phaser와 React가 공유할 Zustand 상태의 최소 구조
- TypeScript와 ESLint 설정
- 2560×1920 초원 월드와 데이터 중심 맵 정의
- WASD와 방향키를 이용한 8방향 이동
- 플레이어를 따라가는 카메라
- 맵 경계와 임시 장애물 충돌
- Esc 메뉴 인벤토리에 체력, 현재 지역, 좌표 표시
- 좌측 아래를 원점으로 하고 위로 갈수록 Y가 증가하는 표시 좌표
- 나무와 돌 생성 지점
- 마우스 방향 근접 공격과 자원 체력
- 마우스 왼쪽 버튼을 길게 누르면 일정 간격으로 반복되는 채집·공격
- 장비별 채집 속도, 전투 속도, 자원 피해, 전투 피해 배율 데이터 구조
- 나무 파괴 시 목재 5개, 돌 파괴 시 돌 4개 획득
- 나무 60초, 돌 90초 재생성
- 5초 간격의 묶음 재생성 검사와 건물 차단 확장 지점
- 미친 토끼 4마리와 데이터 중심 동물 정의
- WANDER, FLEE, ATTACK, HURT, DEAD 동물 상태
- 토끼의 배회, 접근 시 도주, 피격 시 반격, 낮은 체력에서 도주
- 플레이어와 토끼의 체력, 공격, 피격 효과, 체력바
- 플레이어 체력이 0이 되면 시작 지점에서 전체 체력으로 복귀
- 동물 물리 그룹의 월드 경계 충돌, 좌표 보정, 가장자리 이동 방향 보정
- 범용 아이템 정의와 확률·최소·최대 수량을 지원하는 전리품 표
- 토끼 사냥 시 토끼 고기 2개와 토끼 털 1개 획득
- 토끼 포획 시 토끼 털 2개 획득
- 토끼 고기의 음식 재료·허기 회복·동물 먹이 확장 데이터
- 토끼 털의 장비·거점 재료 확장을 위한 재료 분류
- Q 키 포획 모드와 수상한 포획 캡슐 5개
- 체력, 도구 보너스, 동물 난이도 기반의 5~95% 포획 확률
- 포획 조준선, 예상 확률, 성공·실패 처리
- 실제 물리 투사체로 이동하고 회전하는 포획 캡슐
- 캡슐과 동물의 물리 몸체가 직접 겹쳤을 때만 포획 판정
- 포획 캡슐과 동물의 작은 원형 충돌 범위
- 캡슐 적중 시 동물이 축소·회전하며 빨려 들어가는 흡수 효과
- 포획 성공 시 캡슐 맥동과 원형 성공 효과
- 포획 실패 시 캡슐 흔들림과 동물이 다시 튀어나오는 효과
- 빗나간 캡슐은 포획 판정 없이 최대 거리에서 소멸
- 포획 실패 시 토끼의 일시적인 반격
- Esc 메뉴의 5칸 포획 동물 목록과 성별·전투·작업 능력 상세 표시
- B 키 건설 모드와 32픽셀 그리드 스냅
- 1번 거점 코어, 2번 벌목 작업대 선택과 R 키 회전
- 배치 가능 위치의 초록색 미리보기와 불가능 위치의 붉은 미리보기
- 맵 경계, 입구, 물리 오브젝트, 작업 접근 지점, 건물 개수, 거점 반경 건설 판정
- 전체 월드에서 거점 코어 1개 제한
- 거점 코어 중심 480픽셀 건설 및 작업 반경 표시
- 벌목 작업대 1개 작업 슬롯과 회전되는 접근 지점
- 작업 접근 지점 48픽셀 확보 및 해당 영역의 자원 재생성 차단
- 작업대 가까이에서 E 키로 첫 미배치 포획 토끼 배치
- 포획 토끼가 작업 배치를 실행한 플레이어 위치에서 작업대 접근 지점으로 이동하는 연출
- 작업자가 3초 동안 막히면 접근 지점으로 복구하는 처리
- 작업대별 타이머 없이 WorkManager가 생산 시점을 묶어서 갱신
- 작업 시작 후 5초마다 거점 보관함에 목재 1개 자동 생산
- 작업 토끼 흔들림과 작업대 상태 문구
- 건물에 막힌 자원 생성 지점의 재생성 차단 연결
- 중앙 초원·햇살 들판·속삭임 초원·클로버 들판·강변 초원으로 구성된 초원 지역 5개
- 강변 초원과 바위 협곡의 양방향 연결
- 질긴 풀 군락·들판 열매 덤불·구리 광맥 자원
- 몽실 들양과 돌진 멧돼지 동물
- 식물 섬유·구리 광석·들판 열매·양털·멧돼지 가죽과 고기 재료
- 포획 캡슐 묶음·구리 곡괭이·양털 망토·멧돼지 구이 제작법
- 채집·사냥·포획 경험치와 레벨 상승 시 기술 포인트 획득

- 맵마다 제거된 자원, 재생성 시각, 건물 차단 상태 보존

- 맵 재진입 시 작업 토끼를 거점 코어가 아닌 기존 작업대 접근 지점에서 복원

## 기술 스택

- Vite
- React
- TypeScript
- Phaser 3
- Zustand
- CSS
- npm

## 요구 환경

- Node.js 20.19 이상 또는 22.12 이상
- npm

## 설치와 실행

```bash
npm install
npm run dev
```

개발 서버가 출력한 로컬 주소를 브라우저에서 열어 확인합니다.

## 코드 점검 명령

```bash
npm run typecheck
npm run lint
npm run build
```

세 명령을 한 번에 실행하려면 다음 명령을 사용합니다.

```bash
npm run check
```

프로덕션 빌드를 로컬에서 미리 보려면 다음 명령을 사용합니다.

```bash
npm run preview
```

- 개발자 도구에서 저장값을 손상시킨 뒤 새로고침해도 새 게임으로 정상 시작하는지
- 작업대 가까이에서 E를 누르면 토끼가 코어가 아닌 플레이어 위치에서 생성되는지
- 맵을 왕복하면 작업 토끼가 기존 작업대 접근 지점에서 바로 복원되는지
- C 키를 누르면 돌도끼와 강화 벌목도끼 제작 정보가 표시되는지
- 재료가 부족한 상태에서는 인벤토리 수량이 일부만 차감되지 않는지
- 돌도끼 제작 시 목재 5개, 돌 4개, 토끼 털 1개가 차감되는지
- 강화 벌목도끼는 돌도끼 보유 후에만 제작되는지
- 제작한 장비를 장착하면 길게 누르기 채집 간격과 자원 피해가 증가하는지
- 장비 제작 후 새로고침하거나 맵을 이동해도 장착 상태가 유지되는지
- 브라우저 크기를 변경해도 게임 Canvas가 화면을 꽉 채우는지
- Esc로 메뉴가 열리고 게임 월드 움직임이 멈추는지
- 인벤토리·동물·도감·조작키·옵션 탭이 전환되는지
- 인벤토리가 8×8 슬롯으로 표시되는지
- 돌도끼를 오른손 슬롯으로 드래그하면 장착되는지
- 돌도끼를 머리·몸 등 잘못된 슬롯에 놓으면 장착되지 않는지
- 장착 장비를 인벤토리로 드래그하면 해제되는지
- 동물을 포획할 때 동물 탭이 첫 슬롯부터 채워지고 상세 능력치가 표시되는지
- 포획한 종류만 도감에 해금되는지
- 옵션의 게임 저장 버튼을 누르면 저장 시각과 결과가 갱신되는지
- 게임 진행 중 약 12초마다 허기가 1씩 감소하는지
- Esc 메뉴가 열린 동안에는 허기가 감소하지 않는지
- 토끼 고기 1개와 목재 1개로 구운 토끼 고기를 제작할 수 있는지
- 토끼 고기의 먹기 버튼은 허기 8, 구운 고기는 허기 30을 회복하는지
- 허기가 가득 찬 상태에서는 음식이 소모되지 않는지
- 허기 0에서 약 8초마다 체력이 5씩 감소하는지
- 사망 후 허기가 35로 복구되는지
- 새로고침 후 허기와 구운 토끼 고기 수량이 유지되는지
- 개발자 도구의 Elements 탭에서 `canvas`가 한 개만 생성되는지
- 새로고침 후 오류 메시지나 흰 화면이 나타나지 않는지

## 조작법

```text
WASD 또는 방향키 = 플레이어 이동
마우스 왼쪽 클릭 또는 길게 누르기 = 커서 방향 근접 공격 및 자원 채집
Q = 일반 모드와 포획 모드 전환
포획 모드에서 마우스 왼쪽 클릭 = 포획 캡슐 투척
B = 건설 모드 열기/닫기
1 = 거점 코어 선택
2 = 벌목 작업대 선택
3 = 원시 제작 작업대 선택
R = 선택 건물 90도 회전
건설 모드에서 마우스 왼쪽 클릭 = 건물 배치
벌목 작업대 가까이에서 E = 포획 토끼 작업 배치
맵 출구 안에서 E = 연결된 지역으로 이동
C = 가까운 제작 작업대 열기
제작 작업대 클릭 = 작업대 제작 창 열기
Esc = 게임 메뉴 열기/닫기 (열려 있는 거점 창고는 먼저 닫기)
```

저장 데이터는 브라우저 `localStorage`의 `crazy-animal-farm.save.v7.auto`와 `crazy-animal-farm.save.v7.slot-1`~`slot-5` 키에 기록됩니다. 기존 v1~v6 저장은 현재 슬롯 구조와 동물 개체 데이터로 자동 변환됩니다. 모든 기록을 초기화하려면 개발자 도구 Console에서 다음을 실행한 뒤 새로고침합니다.

```js
Object.keys(localStorage)
  .filter((key) => key.startsWith('crazy-animal-farm.save.'))
  .forEach((key) => localStorage.removeItem(key))
```
