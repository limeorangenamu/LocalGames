# 로컬 보드게임

같은 와이파이/LAN 환경에서 여러 사람이 브라우저로 접속해 오목·장기·체스·알까기를 즐길 수 있는 실시간 멀티플레이 게임입니다. 게임 승패에 따라 골드를 얻고, 알까기 말 스킨/이동 효과를 직접 만들어 상점에서 사고파는 커스터마이징 시스템도 포함되어 있습니다.

## 사용 기술

- Node.js
- Express
- Socket.IO
- HTML/CSS/JavaScript

## 실행 방법

### 1. Node.js 설치 확인

터미널에서 아래 명령어를 입력합니다.

```bash
node -v
npm -v
```

Node.js가 없다면 Node.js LTS 버전을 설치하세요.

### 2. 프로젝트 폴더에서 패키지 설치

```bash
npm install
```

### 3. 서버 실행

```bash
npm start
```

성공하면 아래와 비슷하게 나옵니다.

```bash
Omok server running on http://localhost:3000
Other devices on the same Wi-Fi/LAN can connect with http://YOUR_PC_IP:3000
```

### 4. 접속

서버를 실행한 컴퓨터에서는 아래 주소로 접속합니다.

```text
http://localhost:3000
```

같은 네트워크에 있는 다른 사람은 서버 컴퓨터의 IP 주소로 접속합니다.

```text
http://서버PC_IP:3000
```

예시:

```text
http://192.168.0.23:3000
```

## 서버 PC의 IP 확인 방법

Windows 명령 프롬프트에서:

```bash
ipconfig
```

`IPv4 주소`를 찾으면 됩니다.

예시:

```text
IPv4 주소 . . . . . . . . . : 192.168.0.23
```

## 게임 목록

방을 만들 때 아래 네 가지 게임 중 하나를 선택합니다. 먼저 참가한 사람이 흑(초)/두 번째 참가자가 백(한)이 되고, 세 번째 사람부터는 관전자가 됩니다.

- **오목**: 15×15 판. 가로·세로·대각선으로 5개를 먼저 이으면 승리합니다. (렌주룰 기반 3-3 금수 판정 포함)
- **장기**: 표준 장기 규칙. 장군/멍군, 외통수 판정을 지원합니다.
- **체스**: 표준 체스 규칙. 캐슬링, 앙파상, 프로모션을 지원합니다.
- **알까기**: 장기 말판 위에서 말을 튕겨 상대 말을 판 밖으로 밀어내는 게임입니다. 일정 턴마다 능력치 강화 등 보상 선택지가 등장합니다.

플레이어가 방을 나가면 게임판은 초기화됩니다.

## 골드 & 상점

- 두 플레이어가 모두 참여한 상태로 일정 시간(2분) 이상, 각자 최소 3수 이상 둔 정상 대국이 끝나면 승자는 5골드, 패자는 2골드를 받습니다. 기권으로 끝난 게임은 지급되지 않습니다.
- 오른쪽 위 "보관함" 버튼에서 알까기 말 스킨(이미지)과 이동 효과(트레일) 스킨을 직접 만들 수 있습니다.
- "상점" 버튼에서 다른 사람이 등록한 스킨을 골드로 구매하고 장착할 수 있습니다.
- 닉네임이 정확히 `서버장`인 사용자는 상점에 등록된 스킨의 판매 여부를 바꾸거나 완전히 삭제할 수 있는 관리자 권한을 가집니다.

## IntelliJ에서 실행하기

1. IntelliJ에서 이 폴더를 Open합니다.
2. 하단 Terminal을 엽니다.
3. `npm install` 입력
4. `npm start` 입력
5. 브라우저에서 `http://localhost:3000` 접속

├─ README.md
├─ data/
