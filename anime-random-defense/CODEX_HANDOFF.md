# Codex Handoff: Random Defense

이 문서는 Codex가 프로젝트를 이어받기 위한 설명서입니다.

## 1. 프로젝트 목표

학원에서 잠깐 즐길 수 있는 웹 전용 스타 유즈맵식 랜덤 디펜스 게임입니다.

핵심 감성:

```text
랜덤 소환 → 같은 유닛 3마리 합성 → 시너지별 강화 → 정사각형 경로 몬스터 처리 → 보스 점사 → 랭킹 기록
```

## 2. 현재 구현된 토대

현재 프로젝트는 Phaser 3 + TypeScript + Vite 기반입니다.

구현된 핵심 기능:

1. 메인화면
   - 닉네임 입력
   - localStorage 저장
   - 서버 공유 랭킹 TOP 10 표시
2. 게임판
   - 바깥 정사각형 몬스터 경로
   - 안쪽 정사각형 유닛 자유 배치판
3. 유닛 조작
   - 좌클릭 선택
   - 드래그 다중 선택
   - 더블클릭 같은 유닛 전체 선택
   - 우클릭 이동
   - 초록색 선택 원
   - 이동 마커
4. 공격
   - 자동 공격
   - A키 공격 지정 모드
   - 적 좌클릭 점사
5. 랜덤 디펜스 시스템
   - 랜덤 소환
   - 같은 유닛 3마리 합성
   - 선택 유닛 판매
   - 소환 확률 업그레이드
   - 시너지별 공격력 업그레이드
6. 웨이브/패배 조건
   - 총 40웨이브
   - 5/15/25/35웨이브 엘리트
   - 10/20/30/40웨이브 보스
   - 보스 제한시간 초과 시 패배
   - 몬스터 누적 100 이상부터 추가 등장마다 라이프 감소
7. 기록
   - 점수 계산
   - 시너지별 딜량 TOP 3 저장
   - 클리어/패배 모두 랭킹 저장

## 3. 실행 명령

```bash
npm install
npm run dev
```

빌드 확인:

```bash

```

## 5. 핵심 밸런스 위치

밸런스는 대부분 `src/game/balance.ts`에 있습니다.

중요 상수:

- `GAME_RULES`
- `BOARD`
- `SUMMON_RATES`
- `GENRE_UPGRADE_COSTS`
- `GRADE_STATS`
- `UNITS`
- `getMonsterHp`
- `getMonsterSpeed`
- `getNormalSpawnCount`
- `getBossHp`
- `getBossTimeLimitMs`

Codex가 밸런스를 조정할 때는 우선 이 파일부터 보면 됩니다.

## 6. 구현상 중요한 의도

### 칸 배치가 아님

유닛은 격자 칸에 고정되지 않습니다. `BOARD.inner` 범위 안에서 자유 이동합니다.

### 몬스터는 사라지지 않고 순환

일반 몬스터는 목적지 통과로 사라지지 않고 바깥 정사각형 경로를 계속 돕니다.

### 패배 조건

- 일반 패배: 몬스터 누적량이 100 이상인 상태에서 새 몬스터가 나오면 라이프 감소
- 보스 패배: 제한시간 내 보스 처치 실패 시 즉시 패배

### 합성 조건

`같은 등급 3마리`가 아니라 `같은 유닛 3마리`입니다.

합성 결과는 다음 등급에서 랜덤으로 뽑습니다. 같은 시너지 보장은 없습니다.

### 공격력 강화

전체 공격력 강화가 아니라 시너지별 공격력 강화입니다.

## 7. 다음 개선 추천 순서

### 1순위: 조작감 다듬기

- 우클릭 이동 시 유닛끼리 겹침 방지 강화
- 유닛 이동 경로 표시
- 선택 박스 시각 효과 개선
- A키 커서를 실제 빨간 커서 이미지로 교체

### 2순위: UI 개선

- 시너지 업그레이드 버튼을 더 보기 좋게 정리
- 선택 유닛 상세 정보 패널 추가
- 합성 가능 유닛 목록에서 바로 합성 버튼 추가
- 소환 확률 상세 보기 팝업 추가

### 3순위: 전투 피드백

- 피해 숫자 표시
- 치명타 텍스트 표시
- 둔화 상태 표시
- 보스 체력바 상단 고정 표시

### 4순위: 밸런스 조정

현재 수치는 1차 토대용입니다. 실제 플레이 후 다음을 조정해야 합니다.

- 웨이브당 몬스터 수
- 몬스터 HP 성장률
- 보스 HP
- 골드 획득량
- 소환 비용
- 소환 확률 업그레이드 비용
- 시너지 공격력 업그레이드 비용

### 5순위: 데이터 분리

지금은 `balance.ts`에 데이터가 들어 있습니다. 추후에는 다음처럼 나눌 수 있습니다.

```text
src/game/data/units.ts
src/game/data/waves.ts
src/game/data/balance.ts
src/game/systems/combat.ts
src/game/systems/input.ts
src/game/systems/waves.ts
```

## 8. 알려진 한계

- 현재 그래픽은 임시 원형/글자 표현입니다.
- 실제 애니 캐릭터 이미지는 저작권 문제 때문에 넣지 않았습니다.
- Vite 서버 API로 공유 랭킹을 저장합니다. 기록 파일은 `data/rankings.json`입니다.
- 멀티플레이는 없습니다.
- 사운드는 없습니다.
- 모바일 터치는 고려하지 않았습니다.
- Phaser 3 API 기준으로 작성되어 있습니다.
